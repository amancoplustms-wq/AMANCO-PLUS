# أمانكو بلس للشحن والتوريد | AMANCO PLUS TMS

نظام إدارة العمليات اللوجستية والشحن والتوريد المتكامل لشركة **أمانكو بلس (AMANCO PLUS)** في نطاق القاهرة، الجيزة، والقليوبية.

---

## 🌟 مميزات النظام الأساسية

1. **الموقع التعريفي التفاعلي (Public Landing Page):**
   - واجهة عصرية سريعة باللغة العربية مع خط Cairo وهوية أمانكو بلس البصرية.
   - قسم تتبع الشحنات الفوري برقم البوليصة بدون الحاجة لتسجيل دخول.
   - حاسبة أسعار الشحن التفاعلية التقديرية.
   - نموذج انضمام التجار والمناديب وتلقي طلبات الشحن.

2. **لوحة الإدارة والتحكم الشاملة (Admin Dashboard):**
   - متابعة مؤشرات الأداء اللوجستي والمالي في الوقت الفعلي.
   - إدارة الشحنات: إضافة، تعديل، تصدير، وتحديث الحالات.
   - إدارة التجار وقوائم أسعار الـ VIP والخصومات.
   - إدارة المناديب ومناطق التوزيع وحسابات العمولات.

3. **المحرك المالي وتقفيل الحسابات (Finance & Settlements):**
   - تقفيل حسابات التجار واستخراج كشوفات التسوية.
   - تقفيل عهدة المناديب وحساب العمولات وصافي التحصيل اليومي بدقة متناهية.

4. **طباعة البوالص القياسية A4 (Waybill Printing):**
   - دعم 3 أوضاع طباعة: بوليصة واحدة، بوليصتان، أو 4 بوالص في الورقة A4.
   - باركود قياسي Code-128 عالي الدقة متوافق مع كافة أجهزة المسح الضوئي.
   - تمييز بصري فوري لحالة فتح ومعاينة الشحنة (مسموح / غير مسموح).

5. **حزمة الهوية البصرية (Brand Assets Kit):**
   - شعار كامل وأيقونات بصيغ فائقة الدقة 4K وشفافة وفيكتور SVG داخل `/public/brand/`.

---

## 🚀 التقنيات المستخدمة (Tech Stack)

- **Framework:** Next.js (App Router) + TypeScript
- **Styling:** Tailwind CSS
- **Backend & Database:** Supabase (Database, Auth, SSR)
- **Barcodes & Printing:** `react-barcode` + CSS `@media print`
- **Spreadsheets:** `xlsx` لاستيراد وتصدير البيانات المجمعة

---

## 💻 التشغيل المحلي (Local Development)

```bash
# تثبيت الاعتماديات
npm install

# تشغيل بيئة التطوير
npm run dev
```

افتح المتصفح على: [http://localhost:3000](http://localhost:3000)
